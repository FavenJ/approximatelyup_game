**There is no officially confirmed invert mouse setting in Approximately Up yet.** We have not verified a settings toggle, config file flag, or keybind option for mouse inversion, so we will not point you at one that may not exist.

## What is confirmed about mouse input

The mouse is a primary flight input in fly mode. After holding R to launch, you click a joystick or lever to focus it, then steer with WASD or the mouse depending on the control you selected.

**Mouse 3 (middle click)** resets a stuck lever or joystick to neutral. This is the confirmed fix when your ship starts spinning from a jammed input — use it before rebuilding anything.

## What is not confirmed

Whether the demo includes an invert mouse Y-axis (or X-axis) option is **to be confirmed**. Whether the full release in August 2026 adds one is also **to be confirmed**.

No community workaround, config edit, or launch option for inversion has been officially documented either. If a method exists, it has not been verified through an official source.

## How to check for yourself

Press **M** in-game to open the manual, and check the settings menu in the current demo build. If the option matters to your crew, the Steam Community discussions for the game are the confirmed place where players raise control issues with the developers.

This page will be updated the moment an official setting is verified — we only publish confirmed information.
