**An official Approximately Up Discord server invite has not been confirmed yet.** Discord is, however, already the de facto voice and LFG tool for crews — here is what is actually confirmed about how the community uses it.

## Official status

We have not verified an official, developer-run Discord server for the game. Any server claiming to be "the official" one should be treated as **to be confirmed** until the developers link it from the Steam page.

The confirmed official channels are the Steam store page and the Steam Community discussions. If an official Discord launches, it will almost certainly be linked from there — and this page will be updated.

## How crews use Discord today

Voice chat for co-op is typically handled through the Steam overlay or external Discord, and many crews prefer Discord for push-to-talk while building. Four players welding frames and wiring logic at once need clear callouts, and Discord's voice channels fill that role.

Discord LFG channels see traffic during demo periods — players looking for a crew post there. Combined with the Steam Community discussion threads and direct friend invites from the game UI, these are the three confirmed ways to find teammates.

## Finding a crew

- **Discord** — LFG channels during demo extensions
- **Steam Community** — discussion threads for co-op partners
- **Friends list** — invite directly from the in-game UI

No matchmaking system is promised, so crews are organized intentionally. Co-op supports up to four players online.

## Co-op voice etiquette

Confirmed habits that prevent crashes: call out before entering fly mode so nobody deletes a cable mid-throttle, confirm RCS controller lights are green before liftoff, and read the objectives screen aloud together with **O** before launch.

Name your destinations too — "we land at Earth North, not Moonstep" has saved many crews from flying to the wrong pad.
